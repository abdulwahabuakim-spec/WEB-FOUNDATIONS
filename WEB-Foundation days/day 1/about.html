About QuickNotes

QuickNotes is a lightweight web app for capturing ideas fast. It helps students in Arua and beyond to write, organize, and remember important notes without distraction.

How to use QuickNotes

  1. Click on Home to create a new note.
  2. Type your idea and click Save.
  3. Use search to find your notes quickly.
  4. Organize notes with tags for easy access.

Features

  • Fast note creation
  • Offline access
  • Simple and clean design
  • Free for all students

Keyboard Shortcuts

Shortcut Action
Ctrl + N Create new note
Ctrl + S Save current note
Ctrl + F Search notes
